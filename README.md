MoonLight Energy Solutions Solar Project
This repository contains the code and data for the MoonLight Energy Solutions project, focused on identifying optimal locations for solar mini-grids in West Africa.

The project aims to analyze solar potential data to support the deployment of renewable energy solutions.

Current Status: Exploratory Data Analysis (EDA)
Currently in the Exploratory Data Analysis phase, processing solar potential data for:

Benin

Sierra Leone (Bumbuna region)

Togo (Dapaong region)

The notebooks and cleaned data for this task are being developed and managed on a dedicated feature branch (eda-togo).

Repository Structure
data/: Contains raw and cleaned datasets.

notebooks/: Houses Jupyter notebooks for data analysis and exploration.

src/: (Future) For source code files.
